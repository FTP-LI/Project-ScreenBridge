# G3 独立显示实施计划（S2）

> 状态：待执行。目标：把屏桥 IDD 的「第一帧采样写临时文件」改成**逐帧跨进程图像交接**。本阶段不需要平板；驱动安装与宿主运行需要本机管理员，按持续开发计划第六节边界执行。契约见 `docs/CONTRACT.md`。

**Goal**：驱动（WUDFHost / Session 0）把每一帧桌面图像交给登录会话的标准用户进程，且显示器仍为非主屏 1920×1080@60；宿主退出后不遗留失联屏。

**Architecture（工程建议，未验证）**：`EvtIddCxDeviceIoControl` 提供注册/查询控制；`Global\` 命名空间共享内存段 + 命名事件 + 显式 DACL；单帧覆盖槽（sequence + CRC32 + 有界容量），语义对齐 `frame_slot.h`。不预先承诺零拷贝，桌面/托盘逻辑不进驱动。

- [ ] 先写用户态测试：并发 publish/latest、CRC 失配、越界与溢出、旧帧被覆盖、事件丢失、有界缓冲不增长、重复 close 安全；先用**模拟生产者**验证，不依赖驱动。
- [ ] 实现 `frame_bridge` 共享段与事件约定，把 `frame_slot.h` 接为消费者；测试全绿后再动驱动。
- [ ] 改 `Driver.cpp`：去掉 `static LONG recorded` 一次性门闩，逐帧 `CopyResource` → `Map(READ)` → 整帧写入共享段并保持 `AcquiredBuffer.Reset()` / `IddCxSwapChainFinishedProcessingFrame` 时机；实现 IOCTL 回调并补帧统计。
