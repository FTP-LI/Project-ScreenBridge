# G4 视频发送软件准备（2026-11-13）

新增 `apps/windows/streaming/video_sender.py`。它接收已经编码好的 access unit，发送 `SBV1` 能力、关键帧/差分帧和停止消息，并通过现有 SBP1 `write_all` 保持 16 KiB 分片和有界负载；编码器、IDD 帧源和 WinUSB 会话仍由上层接入。

`tests/windows/streaming/test_video_sender.py` 通过 2 项：控制消息/关键帧/差分帧/停止消息的序列和重组，以及 120000 字节 access unit 的有界 SBP1 分片。当前 streaming 测试合计 9 项。

这不是完整画面链路证据。尚未接入 Windows H.264 编码器、真实 `FrameBridge` 帧、平板硬件解码器、Surface/XComponent，也没有在正式签名 HAP 上通过 SBC1 ready 后的视频传输。
