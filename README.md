# 屏桥计划 Project ScreenBridge

让鸿蒙平板通过普通 USB 数据线成为 Windows 电脑的扩展屏，同时将支持 PD 和不支持 PD 的电脑 USB 数据接口纳入兼容目标。

**当前状态：需求整理和技术可行性评估阶段，尚无可运行原型或发布版本。** 下文的功能、性能和兼容性都是开发目标，不代表已经实现。

## 核心目标

- 通过有线连接实现真正的扩展桌面，电脑与平板可以显示不同窗口。
- 同时支持有 PD 和无 PD 的 USB 数据接口，不把 PD 当作画面传输的必要条件。
- 优先使用普通 USB 数据线，不将额外采集卡或转接硬件作为当前方案前提。
- 平板可安装原生鸿蒙应用；日常使用尽量接线即可连接。
- 电脑端最好不安装软件；如果技术验证证明需要显示驱动，明确提出一次安装的备选方案，再确定最终取舍。
- 以未来可公开发布为目标，先验证底层能力，再开发完整产品。

PD 主要涉及供电协商。USB 数据带宽、接口供电方向和是否支持视频输出是不同能力。没有 PD 不应成为软件拒绝连接的理由，但可能无法在使用时维持平板电量。

## 当前技术方向

拟研究的链路为：Windows 扩展显示输出 → 编码 → USB 数据通道 → 鸿蒙应用解码显示。

这只是候选架构。鸿蒙公开接口在目标设备上的可用性、Windows 端驱动需求以及插线自动唤起应用的能力，都需要验证。OpenHarmony 文档中的接口不能直接视为 HarmonyOS 7 已验证可用。

## 换电脑继续开发

首次获取工程：

```powershell
git clone https://github.com/FTP-LI/Project-ScreenBridge.git
cd Project-ScreenBridge
git status --short --branch
```

已有克隆且工作区干净时更新：

```powershell
git pull --ff-only
```

然后按上表顺序阅读文档。目前没有需要安装的项目依赖，也没有构建或运行命令；开发工具的版本需要在第一阶段确认并记录。
